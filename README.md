# Gemini Workspace Enterprise

A premium Next.js marketing and product intelligence site focused on Google Workspace + Gemini Enterprise adoption, enterprise AI workflows, model comparison, pricing clarity, and connector discovery.

## Overview

This project is designed to help enterprise buyers, IT leaders, and workspace admins evaluate Gemini Enterprise in context of:

- Google Workspace integration
- enterprise AI readiness
- model comparison across Gemini and other vendors
- connector and app discovery
- pricing and deployment decisions
- Google Cloud-inspired premium product storytelling

The site is structured as a product-led knowledge hub rather than a generic landing page, with high-trust content, comparisons, and structured data for decision-making.

## What this project includes

- Premium enterprise homepage with Google Cloud-inspired design language
- Product and feature discovery pages
- Model comparison pages for Gemini and other AI vendors
- Enterprise pricing and cost framing
- Connector and app intelligence pages
- Security and readiness sections
- Comparison and benchmark-oriented content for business evaluation
- Search and discovery-focused navigation for connector and product data

## Getting started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

### Production build

```bash
npm run build
```

### Start production server

```bash
npm run start
```

## Notes

This project uses a data-driven architecture with product and comparison content stored under the `data/` folder, making it easier to extend with new features, connector lists, pricing updates, and enterprise comparisons.
